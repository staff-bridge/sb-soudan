# sb-soudan（就活きもち診断）

新卒の就活生向け「就活相談会」に申し込んでもらうための診断サイトです。
公開予定URL： https://staff-bridge.github.io/sb-soudan/

## ファイルの役割

| ファイル | 中身 | よく直すもの |
|---|---|---|
| `js/content.js` | 質問・選択肢・行き先・結果ページの文章 | ★文章を直すときはここだけ |
| `js/config.js` | Googleフォームの送信先、連絡日数 | フォームを作ったら一度だけ |
| `index.html` | トップ・診断・結果の画面 | キャッチコピー、相談会の説明 |
| `entry.html` | 申し込みフォーム | 卒業予定の選択肢 |
| `img/` | ロゴ・イラスト | イラストを入れる |

## イラストの入れ方（unDraw）

1. https://undraw.co/illustrations を開き、右上の色の設定を **`#E0609A`**（ピンク）にする
2. 使いたいイラストを **SVG** でダウンロードする（PNGでも可）
3. 下の名前に変えて `img/` フォルダに入れる（無いあいだは淡い丸が出ます）。PNGやSVGを入れ替えて拡張子が変わったときは、`js/content.js` の `image:`（トップは `index.html`、完了画面は `entry.html` の `data-img`）も同じ名前に直す
   ※ 2026-11-16時点：type1 だけ .svg、ほかは .png

| ファイル名 | 使う場所 | おすすめの絵柄 |
|---|---|---|
| `hero.svg` | トップ | 人が考えている・話している |
| `type1.svg` | ① 自己分析 | 自分をふり返る・探す |
| `type2.svg` | ② 業界・企業選び | 道や選択肢を選ぶ |
| `type3.svg` | ③ ES・書類 | 書類・パソコンで書く |
| `type4.svg` | ④ 面接 | 向かい合って話す |
| `type5.svg` | ⑤ スケジュール | カレンダー・計画 |
| `type6.svg` | ⑥ メンタル | ひと休み・リラックス |
| `thanks.svg` | 申し込み完了 | よろこぶ・ハイタッチ |

※ unDrawの規約で、イラストをAIの学習に使うことは禁止されています。

## Googleフォームのつなぎ方

1. Googleフォームを新しく作り、**次の15問をすべて「記述式（短い回答）」で**作る（順番は自由。必須設定はしなくてOK。チェックはサイト側でしています）
   氏名／ふりがな／メールアドレス／電話番号／学校名／卒業予定／第1希望日時／第2希望日時／第3希望日時／参加方法／相談したいこと（※これだけ「段落」）／診断タイプ／就活の進み具合／話し方の希望／流入元
2. フォーム右上の「︙」→「事前入力したURLを取得」を開き、各欄に適当な文字（例：a, b, c…）を入れて「リンクを取得」
3. できたURLの中の `entry.123456789=a` のような部分の **数字** を、`js/config.js` の `entry` の同じ項目に書き写す
4. フォームのURLの `/viewform` を `/formResponse` に変えたものを `formAction` に書く
5. フォームの「回答」タブ → スプレッドシートにリンク（回答が表にたまる）
6. 「回答」タブ →「︙」→「新しい回答についてのメール通知を受け取る」で社内通知（チームの共有アドレスで作ると、みんなに届きます）

`formAction` が空のあいだは「テストモード」で、送信しても届きません（画面上にも黄色い表示が出ます）。

## 自動返信メールと社内通知

`gas/autoreply.gs` を Googleフォームに組み込みます。申し込みがあると、
**社内に通知メール**（学生の情報・診断結果・希望日時をすべて記載）と、**学生に受付メール**が自動で届きます。
メールは、フォームを作ったGoogleアカウントから送られます。

1. Googleフォームの編集画面 → 右上の「︙」→「**スクリプト エディタ**」を開く
2. 最初から入っている文字（`function myFunction() {}`）を全部消して、`gas/autoreply.gs` の中身を全部貼り付ける
3. 上のほうの「設定」の `NOTIFY_TO` に、社内通知を受け取るアドレスを書く（複数なら `a@…, b@…`）
   ※ 実際のアドレスはこの GitHub（公開）には書かないこと
4. 💾（保存）を押す
5. 上の関数の選択欄で「**setup**」を選んで「**実行**」を押す
6. 「承認が必要です」→ 自分のアカウントを選ぶ →「**許可**」
   （「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」→「許可」。自分で作ったものなので問題ありません）
7. 下に「設定できました」と出たら完了。サイトから自分のメールアドレスでテスト申し込みして、2通届くか確認する

文面を直すときは、スクリプト エディタの `replyBody`（学生あて）、`notifyBody`（社内あて）を書き換えて保存するだけでOK（setup の再実行は不要）。

## 流入元（どこから来たか）の付け方

URLの最後に `?from=名前` を付けると、申し込み時に「流入元」として記録されます。

- Instagram： `https://staff-bridge.github.io/sb-soudan/?from=insta`
- LINE： `https://staff-bridge.github.io/sb-soudan/?from=line`
- 〇〇大学で配るチラシ： `https://staff-bridge.github.io/sb-soudan/?from=〇〇大学`

QRコードは **https://staff-bridge.github.io/sb-soudan/qr.html**（社内用のQRコード作成ページ）で、場所の名前を入れて作れます。名前は半角英数字と「-」だけにしてください。**QRコードを印刷したあとは、サイトのURL（sb-soudan の部分）を変えないでください。**

## 更新するときの注意

- スマホが古いファイルを覚えていることがあるので、`css` や `js` を直したら、`index.html` と `entry.html` の中の `?v=20261118g` の部分を新しい文字（例：日付）に変えてください。
- 日本語の改行位置は BudouX（`js/vendor/`）で自動調整しています。文章を直しても再作業は不要です。
